## Project Overview

ATM Project provides a small, browser-ready banking interface that models a familiar set of ATM tasks. Users can enter and validate a PIN, view the current balance, deposit money, and submit a withdrawal request.

Built with HTML, CSS, and JavaScript, the project offers a practical example of front-end application behavior. The codebase can be used to study DOM updates, event-driven interactions, and the implementation of a basic banking flow without a large framework.

---

## Included Functionality

- PIN validation before ATM features become available
- Display of the current account balance
- Deposit process for adding funds
- Withdrawal process for requesting cash
- User interface that runs in a web browser
- HTML markup defining the application structure
- CSS rules for layout and visual presentation
- JavaScript handling DOM manipulation and application behavior
